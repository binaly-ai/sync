About Binaly Sync

Version

Binaly Sync keeps the lab's folders connected to Binaly. It finds the files in the folders you chose, sends them to the lab's Binaly, and notices new and changed ones. It contains no AI and decides nothing on its own: for each file, Binaly says whether to send it.

Reading the files and writing them into the lab's notes is done separately, by the lab's AI assistant (Claude Desktop) as a scheduled task. The AI assistant page in this window shows how to connect it and set that up.

To remove Binaly Sync: Windows Settings, Apps, Installed apps, Binaly Sync, Uninstall. Files already in Binaly stay there.
